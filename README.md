# FitHub-Smart-Fitness-Assistant-using-Computer-Vision
FitHub is a smart fitness assistant that uses computer vision and pose estimation to monitor and analyze workout performance in real time. Developed using Python, OpenCV, and MediaPipe, the system tracks body movements during bicep curl exercises by identifying key body landmarks and calculating joint angles. It automatically counts repetitions, evaluates posture, and provides instant feedback to ensure exercises are performed with correct form.

The application helps users improve workout efficiency by reducing the need for manual repetition counting and personal supervision. By continuously monitoring movement patterns, FitHub can identify incorrect exercise techniques that may lead to poor performance or injuries. Real-time feedback enables users to make immediate corrections, promoting safer and more effective workouts.

This project demonstrates the practical application of computer vision, pose estimation, and real-time motion analysis in the fitness domain. It showcases how intelligent systems can be used to create interactive fitness solutions that enhance user engagement and training outcomes. The platform can be further expanded to support multiple exercises such as squats, push-ups, lunges, and other fitness activities, making it a scalable and versatile fitness monitoring solution.
